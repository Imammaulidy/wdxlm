# ==============================================================================
#            BOT ADB TERMINAL STANDALONE — BITGET QRIS MORPH MACRO
# ==============================================================================
# File master koordinat layar HP (Standar: 1080x2400 @ 352 DPI).
# Anda dapat mengubah angka koordinat dan jeda sleep langsung di sini.
# Untuk menonaktifkan step tertentu, tambahkan tulisan OFF di judul step.
#
# PANDUAN PERINTAH:
#   [ID. Nama Langkah]       -> Judul Langkah (tambah OFF untuk skip)
#   input tap X Y            -> Klik koordinat layar
#   sleep DETIK              -> Jeda detik (contoh: sleep 2.0)
#   input swipe X1 Y1 X2 Y2  -> Geser layar
#   pin {PIN}                -> Ketik PIN transaksi dinamis sesuai keypad
#   input text TEKS          -> Ketik teks langsung via ADB
#   input keyevent KODE      -> Tombol sistem (4=Back)
# ==============================================================================
