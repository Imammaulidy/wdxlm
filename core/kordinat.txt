# untuk automasi bot WD XLM Bitget.

# PANDUAN FORMAT PERINTAH:
#   [ID. Nama Langkah]              -> Judul Step / Bagian (Tambah OFF jika di-skip)
#   input tap X Y                   -> Tap / klik koordinat layar
#   sleep DETIK                     -> Jeda waktu (contoh: sleep 1.5)
#   input swipe X1 Y1 X2 Y2 DURASI  -> Geser layar (durasi dalam milidetik)
#   input text TEKS                 -> Ketik teks ({ALAMAT_WD}, {ACCOUNT_NUM}, {PIN})
#   input keyevent KODE             -> Tombol sistem (4=Back, 187=Recent Apps, 279=Paste)
#   pin {PIN} JEDA_AKHIR            -> Ketik PIN dinamis sesuai keypad di config.json
#   monkey -p NAMA_PAKET ...        -> Buka aplikasi via package manager
# ==============================================================================
